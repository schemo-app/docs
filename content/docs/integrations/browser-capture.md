Schemo Bridge captures requests from the browser tabs you choose and sends them to the desktop app on the same machine. Install [Schemo Bridge](https://github.com/schemo-app/extension) for Chrome, Edge, or Firefox.

## Capture a request

1. Start Schemo and open **Capture** in the sidebar.
2. Go to the browser tab you want to inspect. Open Schemo Bridge from the toolbar and enable capture for that tab. The browser may ask for access to the site.
3. Trigger the API action in the tab. Select the captured request in Schemo.
4. Inspect its response or repeat the request from the desktop app.

Capture controls let you pause an individual tab or pause all tabs. You can filter the visible requests to focus on a URL, slow replies, or errors.

If the extension shows as disconnected, check that the desktop app is running and that the right browser extension is installed. See [Troubleshooting]({{< relref "/support" >}}).
