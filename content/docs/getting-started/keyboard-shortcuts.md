These shortcuts apply in the Schemo desktop app. Use **Cmd** on macOS and **Ctrl** on Windows and Linux. The app menu lists the same commands next to their current combinations.

## General

| Action | Default shortcut |
| --- | --- |
| Command palette | Cmd/Ctrl + K |
| Settings | Cmd/Ctrl + , |
| Show or hide the sidebar | Cmd/Ctrl + B |
| Check for updates | Cmd/Ctrl + U |
| Open the history | Cmd/Ctrl + Y |

## Fixed shortcuts

These combinations cannot be reassigned.

| Action | Shortcut |
| --- | --- |
| Switch to the next or previous open tab | Ctrl + Tab, Ctrl + Shift + Tab |
| Zoom the interface in, out, or back to the default | Cmd/Ctrl + =, Cmd/Ctrl + −, Cmd/Ctrl + 0 |
| Paste a list, query string, or cURL command into **Params** or **Headers** | Cmd/Ctrl + V on a row |
| Close the palette, a popover, or a dialog | Esc |

Hold **Ctrl** and press **Tab** repeatedly to step through open tabs. Release **Ctrl** to open the highlighted one.

## Change a shortcut

Open **Settings → Keyboard shortcuts**. The page shows the combinations for your platform. Search by command name or by keys, select a combination, and press the replacement keys. Press **Esc** to cancel recording.

If another command already uses the combination, Schemo names that command and offers **Reassign**. Use **Back to the default** beside a command to restore one combination, or **Reset all** to restore every default. The sidebar of the settings page counts how many combinations you have changed.
