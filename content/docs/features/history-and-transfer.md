## Find a previous request

Open **History** in the sidebar and search for a request by URL or method. Select a record to inspect its response, then repeat it or reopen it in the request editor.

## Bring in existing requests

Use **Import** to bring in a Schemo file, a Postman or Insomnia collection, an OpenAPI document, or a HAR file. Review the import preview and choose where to put the requests. Check imported environments and authorization before sending.

You can also [paste a cURL command]({{< relref "/guides/import-curl" >}}) directly into an HTTP request address.

## Share a collection or a request

Export a collection in Schemo format when you want to preserve Schemo-specific request definitions. You can also export supported collections to formats such as Postman, OpenAPI, or Insomnia. For a single request, use the copy actions to get a command or snippet such as cURL, Fetch, or PowerShell.

Review any export that includes credentials before sharing it. See [Local data]({{< relref "/support/local-data" >}}).
